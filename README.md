# CodeNewLigma Nerd Font 
### CodeNewRoman Nerd Font but with ligatures
Based on [CodeNewRoman by Sam Radian](https://github.com/ryanoasis/nerd-fonts/tree/master/patched-fonts/CodeNewRoman).  
I only added the lig*m*atures from [FiraCode (by Nikita Prokopov)](https://github.com/tonsky/FiraCode), using the Ligaturizer app by Ilya Skriblovsky (https://github.com/IlyaSkriblovsky), Navid Rojiani (https://github.com/rojiani) and ToxicFrog (https://github.com/ToxicFrog)).  
(i hope that includes everyone who participated in the creation of this font)  

# Installation
### Windows / MacOS
1. Download the zip file from the [Releases page](https://github.com/xLEVK1NGx/CodeNewLigma/releases)
2. Extract it
3. Select all fonts from the OTF/ folder and install them.

### Linux
##### Arch
Download packaging/arch/PKGBUILD and run `makepkg -sic` in the same folder as the PKGBUILD

##### Other distros
1. Download and extract the zip archive from the [Releases page](https://github.com/xLEVK1NGx/CodeNewLigma/releases)
2. Run the `install.sh` wizard

# Usage
The font should become registered system-wide as CodeNewLigma, with 3 variations: CodeNewLigma, CodeNewLigma Mono, and CodeNewLigma Propo, each with a Regular, Bold, and Italic styles.

Then pick your font family:
- If you are limited to monospaced fonts (because of your terminal, etc) then pick a font with Nerd Font Mono (or NFM).
- If you want to have bigger icons (usually around 1.5 normal letters wide) pick a font without Mono i.e. Nerd Font (or NF). Most terminals support this, but ymmv.
- If you work in a proportional context (GUI elements or edit a presentation etc) pick a font with Nerd Font Propo (or NFP).
